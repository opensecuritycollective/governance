## Principios clave

* Investigación ética y verificable.
* Software y metodologías en código abierto (Apache 2.0 cuando aplique).
* Divulgación coordinada antes de cualquier publicación de fallos.
* Meritocracia de contribución bajo el Código de conducta de la organización.
